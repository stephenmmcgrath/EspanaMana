# España Mana - Web Version

This is a lightweight, dependency-free web application version of **España Mana**, ready to be hosted on GitHub Pages.

## Features
- **500 Spanish Words**: Spanning 3 difficulty levels (Simple, Intermediate, Difficult).
- **Pulsing Animations**: Clean UI with glowing text effects.
- **Audio & Haptics**: Uses Web Speech API for pronunciation, Web Audio API for feedback beeps, and `navigator.vibrate` for haptics on supported mobile browsers.

## How to Host on GitHub Pages
1. Log in to [GitHub](https://github.com/).
2. Create a new repository (e.g., `espana-mana-web`).
3. Extract this ZIP file and upload all the files (`index.html`, `style.css`, `script.js`, `icon.png`, `README.md`) directly to the root of your new repository.
4. Go to the repository's **Settings** tab.
5. In the left sidebar, click on **Pages**.
6. Under **Build and deployment > Branch**, select `main` (or `master`) and click **Save**.
7. Wait a minute or two, and GitHub will provide you with a live URL (e.g., `https://<yourusername>.github.io/espana-mana-web/`). 

You can now access your flashcard app from any mobile or desktop browser!
